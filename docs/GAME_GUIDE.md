# NEON CIRCUIT

画像生成したSFの戦闘ステージ、キャラクター、敵が登場する、ブラウザで遊べる2D自動攻撃ハクスラです。

## タイトル画面とオープニング

`index.html` を開くと、最初に開始ボタンが出ます（ブラウザは操作の前に音を鳴らせないため）。押すとオープニングムービー（約68秒）が流れ、タイトル画面に移ります。

- ムービーは **Esc** か右下の「スキップ」で飛ばせます。Enter / Space は2回押すとスキップです。
- タイトル画面では **↑↓**（または W / S）で選び、**Enter** で決定、**Esc** で戻ります。マウスやタッチでも操作できます。
- 「出撃する」でクラス選択へ進みます。「オープニングを見る」で再生し直せます。「サウンド設定」で音楽と効果音を別々に切り替えられます。戦闘中は Esc メニューの「設定」で切り替えられます。
- タイトル画面で75秒操作しないと、オープニングがもう一度流れます。
- OSで「視差効果を減らす」を有効にしている場合、起動時のムービーは自動再生されません。メニューからは再生できます。
- 戦闘終了後の画面から「タイトルへ戻る」で戻れます。

ゲーム用のムービーは `assets/movie/opening.mp4` に収録しています。動画・音源の取得にはGit LFSが必要です。

## 遊び方

タイトル画面で「出撃する」を選び、クラスとマスタースキルを選んで出撃します。移動は **WASD / 矢印キー**。タッチ画面では戦闘エリアをドラッグして移動します。攻撃と回復などのアクティブスキルは、コストがたまると自動で発動します。

戦闘は画面全体を使った斜め見下ろしの3D表示です（three.js r187 を `vendor/three.bundle.js` に同梱しているので、ネットに繋がっていなくても動きます）。WebGL2 が使えない環境では従来の2D表示に切り替わります。

### ロボットのモデル

レンジャー・タンク・アサシンと、ドローン・追撃機・射撃型エリート・ボスは、Blender 5.2 のスクリプトで組み立てた3Dモデルです（待機・走り・攻撃のアニメーション付き）。モデルは `vendor/models.js` に埋め込んであり、ファイルを直接開いても読み込めます。作り直すときは `tools/robots/build_players.py` / `build_enemies.py` を Blender で実行し、`tools/robots/embed_models.py` で埋め込み直します。モデルを読み込めない環境では、簡易モデルで表示します。

### Esc メニュー

戦闘中に **Esc**（または右下の「メニュー」）を押すと一時停止し、メニューが開きます。もう一度 **Esc** で戦闘に戻ります。**Q / E** でタブを切り替えられます。

- **スキル回路**: 所持する強化ノードをスキルの下へドラッグして直列接続。右側の最終性能と実際の戦闘へすぐ反映されます。
- **設定**: BGM、効果音、画質（低 / 中 / 高）、発光エフェクト、ダメージ数値、画面の揺れ、カメラ追従。変更はすぐ反映され、次回の起動でも引き継がれます。
- **通信ログ**: それまでに受信した通信の読み返し。
- **タイトルへ戻る**: 今回の出撃を終了してタイトルへ。

画面下中央のアイコン列は各スキルの充填状況です。枠のリングが一周すると充填完了（緑）で、数字は残り秒数です。

クラス固有のサブスキルと、選んだマスタースキルの2つで出撃します。レベルアップやボス報酬でスキルを増やし、最大17種を同時に装備できます。コストはスキルごとにたまり、発動条件を満たしたものから自動で発動します。

新スキルは、連鎖放電のチェインアーク、遅れて着弾するオービタルストライク、正面を斬るフォトンスラッシュ、敵を減速させるクライオフィールド、敵を引き寄せるグラビティウェル、防御用のイージスドームです。引き寄せた敵に爆撃を重ねるなど、複数のスキルを同時に装備して効果を組み合わせられます。

画面下のスキルアイコンに、充填が終わるまでの秒数が表示されます（マウスを重ねると詳細）。リングが緑の「充填完了」は、射程内に敵が入る、耐久値が減るなど、発動条件を待っています。周期発動のショックリングは次の発動までの秒数、常時効果は紫のリングで表示します。

レベルアップ時には3択からスキル、ノード、強化を選びます。出撃時には12個の未接続ノードを持っています。Esc →「スキル回路」で、パレットからスキルの下へつないでください。途中をつかむと、それ以降のノードがまとめて移動します。各スキル最大64個、接続1個につき全体の効果量が5%上がります。前後の増幅ノードを組み合わせると、順番によって火力が変化します。詳しい操作は[強化画面ガイド](VISUAL_SKILL_EDITOR.md)を参照してください。

## 時間モード

- **ラッシュ**: 敵部隊を全滅させると即進行。敵の追加出現は各ラウンド13秒 / 13秒 / 22秒までです。全10ウェーブの所要時間は戦い方で変わります。
- **約1時間**: 90秒 / 90秒 / 180秒（全10ウェーブで約60分）
- **指定時間**: 5分 / 5分 / 10分（全10ウェーブで約200分）

指定の各ラウンド時間と「最後まで約1時間」は両立しないため、別モードにしています。どのモードも10ウェーブ、各3ラウンドで進みます。各ラウンドは制限時間が過ぎ、残った敵を倒すと終了します。各ウェーブ末にボスが出現し、5ウェーブ目と10ウェーブ目は強化ボスです。

出撃後は節目のウェーブで救出作戦の通信が届きます。「通信ログ」を開くと、それまでの通信を読み返せます。橙の照準線は射撃型エリートが弾を撃つ方向、赤い予告円はボスの攻撃範囲です。追撃機は紫の尾を引いて高速で接近します。後半のボス戦では、最初の着弾後に同じ場所へ追撃が来ることがあります。

## 戦闘BGM

通常戦は提供曲「Metal and Nerve」（約2分57秒）、ボス戦は新規制作した「Core Lockdown」（144 BPM、約27秒）がループします。音源は `assets/audio/Metal_and_Nerve.mp3` と `assets/audio/core-lockdown.mp3` に入っています。提供曲は元のファイルを収録し、ゲーム側で再生音量を調整しています。ゲームを一時停止したり、スキル選択や通信ログを開いたりすると、戦闘BGMも一時停止します。

単発、散弾、ビーム、追尾弾、軌道爆撃の発射音と、爆発・着弾・敵弾の効果音は、波形とノイズから合成しています。既存の作品や効果音素材からサンプリングした音は使っていません。

## 画像

`assets/cover.png` は画像生成ツールで制作したタイトル画面用アートです。プロンプトは「見下ろし型の廃棄軌道ステーションで、遠距離型の小さなSF戦士が幾何学的なドローンに囲まれる。シアンと紫のエネルギー、濃紺の建築、フラットな2Dゲームキービジュアル。左側にタイトル用の余白。文字・UI・ロゴなし」です。

戦闘用素材も内蔵の画像生成ツールで制作しました。

- `assets/units/` は「透明背景、真上から見た3クラスと3種類の敵、ネオン装甲、輪郭が読みやすい2Dスプライト」の6点です。
- `assets/skills/` は「暗い紺地に発光するSFスキルのシンボル、弾・ビーム・回復・移動・防御など」の17点です。追加素材のモチーフは連鎖電撃、軌道爆撃、光刃、冷却波、磁力、防御ドームです。
- `assets/arena.webp` は「真上から見た軌道ステーションの戦闘床、暗い鋼板と控えめな円形回路、キャラクターや文字なし」の1点です。
- `assets/reactor.webp` は「軌道施設の巨大な反応炉、赤い異常信号、青い救助艇を描いたSFイラスト」です。

## オープニングとタイトルの素材

- **ムービーとタイトル背景**: Blender 5.2（EEVEE）でレンダリングした3DCGです。軌道施設アーク、通路、軌道砲、降下艇、ロゴはスクリプトで組み立てたモデルです。
- **ヒーローとボスのカット**（`RANGER` / `TANK` / `ASSASSIN` の登場、3人の後ろ姿、戦闘3枚、CIRCUIT-0 の2枚）: 画像生成ツールで制作した一枚絵に、Blender 上でカメラの動き・粒子・火花・発光を重ねています。
- **見下ろしの戦闘カット**: ゲーム本編のユニット画像（`assets/units/`）と戦闘床（`assets/arena.webp`）をそのまま使い、ビームや衝撃波を3Dで足しています。
- **外壁テクスチャ**: 画像生成ツールで制作した継ぎ目なしの装甲板と機械ディテールです。
- **地球**: NASA Visible Earth の Blue Marble と夜景（パブリックドメイン、Wikimedia Commons 経由で取得）。雲は手続き生成です。
- **音楽と効果音**: Python で合成したものです（120 BPM、ニ短調。カットはすべて小節線に合わせています）。`assets/audio/title-theme.wav` はタイトル用の32秒ループです。
- **フォント**: Michroma と Zen Kaku Gothic New（どちらも SIL Open Font License。ライセンス文は `assets/fonts/` に同梱）。

オープニングの全制作データはこのリポジトリには収録していません。追加素材の制作・共有方法は管理者と相談してください。
